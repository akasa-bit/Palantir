# 小説読解オントロジー

入試の小説問題用に、小説を「出来事・心情・仕掛け・人物・関係・場面」に分解し、すべてを本文の引用にひもづける形式。

- `reading.html` … 説明と「羅生門」の見本（ブラウザで開く）。`reading.src.html` にデータを埋め込んで生成
- `rashomon_text.json` … 本文（青空文庫、底本「芥川龍之介全集1」ちくま文庫。段落ごと、ルビなし）
- `build_rashomon.py` … 見本データの定義と検査。`rashomon.json` を書き出す
- `template/` … 自分で記入するための空の表
- `check_quotes.py` … 記入した表の引用を本文と照合する
