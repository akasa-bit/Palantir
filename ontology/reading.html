Reading Ontology ／ 入試の小説問題

小説を「モノと関係」に分解して読む

入試の小説問題は、ほぼ「きっかけ → 心情 → 行動」のつながりを、本文の根拠つきで説明させる問題。だから形式化するのもそこ。出来事・心情・表現の仕掛けを別々のモノとして取り出し、必ず本文の引用にひもづける。

01 型

取り出すモノは6種類

真ん中の横1列が小説問題の骨格。「傍線部の心情を説明せよ」は心情とそのきっかけを、「なぜそうしたのか」は行動から心情へ逆向きに、「表現の効果を説明せよ」は仕掛けとそれが重なる心情を聞いている。

登録のルール（これが形式化のいちばん大事な部分）

  • 根拠なしは登録不可心情も仕掛けも、本文の引用が一字一句合っていないと入れられない。「なんとなくそう思う」を締め出す。
  • きっかけは心情より前心情には必ずきっかけの出来事をつける。きっかけが心情より後に語られていたら、設計ミスか回想。
  • 明示と暗示を分ける語り手が言葉で述べた心情か、行動や様子から読み取った心情か。暗示のほうが設問になりやすい。
  • 解釈は解釈と書く仕掛けの「効果」は本文に書いていない。事実（引用）と解釈を別の欄に分ける。

下の「羅生門」の見本では、引用56件すべてをプログラムで本文と照合してある。1件でも合わなければ、データが書き出されない仕組みにしてある。

03 分かること

形式化して見えた「羅生門」の仕組み

  1. 心情が7段階で動き、最初と最後が対になっている。M2「盗人になる勇気が出ない」で始まり、M7「盗人になる勇気」で終わる。途中の5つは、その距離を埋めるための段差。
  2. 真ん中で一度、逆方向に振れる。M4 では悪を憎み「飢え死にを選ぶ」ところまで行く。いったん反対側に振ってから落とすので、最後の転落が際立つ。本文自身が「全然、反対な方向」と言っている。
  3. 下人の心情はすべて「明示」。語り手が全部説明してくれる作品なので、設問は「どこに書いてあるかを見つけて、まとめる」型になる。逆に老婆の心情（M8）は暗示だけ。
  4. きっかけは毎回、老婆の行動か言葉。下人は自分からは変わらない。外の出来事に押されて変わる人物として作られている。
  5. 語られる順と起きた順がずれるのは1か所だけ。E1（暇を出される）だけが回想。ここが下人の状況説明になっている。
04 自分でやる

過去問の小説でやる手順

  1. 段落に番号を振り、場面で区切る。場所・時・登場人物が変わるところが境目。
  2. 出来事を拾う。「誰が何をした」を1行ずつ。回想には印をつける。
  3. 心情を拾い、引用を写す。心情語（嬉しい、憎悪…）は明示。行動・表情・せりふ・情景から読むものは暗示。
  4. 心情ごとに、きっかけと行動を線でつなぐ。つなげない心情があれば、読み落としがある。
  5. くり返し出てくる物・比喩・情景を「仕掛け」として拾う。どの心情と重なるかを書く。
  6. 設問の傍線部がどのモノに当たるかを決めて、線をたどって答える。
設問の型たどる向き答えの骨組み
心情説明心情 → きっかけ〜（きっかけ）によって、〜という気持ち。
変化の理由前の心情 → きっかけ → 後の心情〜だったが、〜をきっかけに、〜になったから。
行動の理由行動 → 心情 → きっかけ〜を受けて〜と感じ、〜しようと思ったから。
表現の効果仕掛け → 重なる心情〜を描くことで、〜（心情・状況）を印象づける効果。
