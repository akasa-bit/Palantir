# オントロジー捜査線

町を歩く群衆の中から、記録（オントロジー）のつながりをたどって犯人ひとりを割り出すゲーム。

**遊ぶ**：https://claude.ai/artifact/L7ef7MVUgy1BeriAETxKb7
（非公開のページ。ほかの人に見せるときは、ページの共有メニューから共有する）

- `detective.html` … 本体（Artifact として公開する形式。ブラウザで直接開いても動く）
- 記録の種類：人物・場所・車両・電話・通話・滞在記録・取引・事件・証言
- 事件は3難度。町と事件は毎回自動生成し、手がかりを全部重ねると犯人が1人に決まることを生成時に検査している

## 遊び方

やることは「証言を読む → 記録をたどって人を絞る → 重なった1人を逮捕」の3つ。誤認逮捕は2回で打ち切り。

### 画面

- 左の地図：町の人が歩いている。赤い点線の建物が事件現場。人物や建物を押すと詳細が開く
- 右のパネル
  - 事件ファイル：事件の時刻・現場と証言
  - 探索：記録を絞り込む（最大3本）
  - 詳細：選んだ記録の中身と、つながっている記録

### 操作

- 建物を押す →「（時刻）にここにいた人を探す」で、その時刻の該当者が出る
- 探索に並ぶ値（例：上着　赤3　青1）を押すと、その値で絞り込む。右の数字は該当件数
- 「→ 滞在記録」などのボタンで、つながった記録へ移る
- 詳細画面の点線の値を押すと、同じ値の記録を探索に出せる。「まとめて探索へ」でリンク先を一括で送れる
- 取引の詳細にある「（時刻）にこの店にいた人を探す」で、買い物をした人物の候補が出る
- 手順の × を押すと、そこから後ろを取り消す
- 人物に行き着いた探索の該当者は、地図で色の輪がつく。すべての探索に当てはまる人には ◆ がつく

### 事件1の最短手順

1. 赤い点線の建物（宝石店）を押す
2. 「にここにいた人を探す」を押す
3. 証言どおりに上着と髪色の値を押す
4. 残った1人の名前を押して「逮捕する」

### 事件2・3の入口

- 事件2：探索を「取引」から始めて品目のバールを押し、その取引の詳細から店にいた人を探す。逃走車は「車両」から車種と色を押して「→ 所有者」
- 事件3：証言の電話番号を押し、購入取引から店にいた人を探す。駅は建物を押して発生時刻で探す。同じ電話の発信通話をたどると、犯人の知人にかけた人物が出る
