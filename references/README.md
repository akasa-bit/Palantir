# オントロジー文献 500件

- `ontology_references.csv` … Excel で開ける一覧（番号・分野・タイトル・著者・年・掲載誌・被引用数・DOI）
- `ontology_references.bib` … 文献管理ソフト（Zotero など）に取り込める BibTeX
- `ontology_references.json` … 全項目入りの元データ
- `scripts/` … 収集（Crossref API）と選定に使ったスクリプト

収集日: 2026-11-14。被引用数は Crossref の集計値。選び方の詳細は `docs/ontology-guide.html` の末尾を参照。
